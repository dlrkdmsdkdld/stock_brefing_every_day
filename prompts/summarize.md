이 디렉터리는 보유 주식 브리핑 파이프라인이다. 지금은 뉴스 요약·판단 단계다.

1. `news.json`을 읽는다. `news`는 종목별로 `stories` 배열을 가지고, 각 story에는
   `title`, `body`(있을 수도 없을 수도 있음), `body_source`, `sources`, `published_kst`가 있다.
2. `body`가 있는 story만 대상으로 한다. `body`가 없는 story는 건너뛴다(제목만으로 판단하지 말 것).
3. 각 대상 story마다 본문을 읽고 아래를 작성한다. 모두 한국어로, 본문에 있는 내용만 쓴다.
   - `summary`: 기사 내용 2~3문장 요약. 숫자·기업명·날짜 등 구체적 사실을 반드시 포함한다.
   - `stance`: 해당 종목에 대해 "호재" / "약한 호재" / "중립" / "약한 악재" / "악재" 중 하나.
   - `impact`: 왜 그 stance인지 1~2문장. 보유 종목에 미치는 경로를 구체적으로 쓴다.
   - `caution`: 근거의 한계나 반대로 볼 여지. 없으면 빈 문자열.
4. 결과를 `verdicts.json`에 아래 형식으로 **덮어쓴다**. 키는 기사 제목을 정규화한 값이며,
   정규화는 소문자로 바꾼 뒤 숫자·영문·한글 이외의 문자를 모두 제거한 것이다
   (파이썬: `re.sub(r"[^0-9a-z가-힣]", "", title.lower())`).

```json
{
  "generated_at": "ISO8601 (Asia/Seoul)",
  "analyst": "Claude가 기사 본문·요약을 읽고 작성. 키워드 감성분석이 아니며 투자 자문이 아님.",
  "verdicts": {
    "<정규화된제목>": {
      "title": "원래 제목",
      "holding": "종목 이름",
      "stance": "호재",
      "summary": "...",
      "impact": "...",
      "caution": "..."
    }
  }
}
```

규칙:
- 본문에 없는 수치나 사건을 지어내지 않는다. 확신이 없으면 "중립"으로 두고 `caution`에 이유를 쓴다.
- 기사 주제가 보유 종목이 아니라 다른 회사이고 보유 종목은 언급만 된 경우 "중립"으로 하고 그 사실을 `caution`에 적는다.
- 파일을 쓸 때는 파이썬으로 `json.dump(..., ensure_ascii=False, indent=2)`를 쓴다.
- 작업이 끝나면 몇 건을 처리했고 몇 건을 건너뛰었는지 한 줄로 보고한다. 다른 파일은 건드리지 않는다.
